Common questions

  • How do I open the sidebar? Open any Google Doc, then click Extensions → Doc Table Formatter → Open sidebar.
  • Does the add-on store any data? No. It runs entirely inside the document you have open and does not transmit data to external servers. See our Privacy Policy.
  • What permissions does it need? Access to the current document (documents.currentonly) to format the table you select, and permission to display its sidebar and menu (script.container.ui). Google Workspace Marketplace also requests account-identification permissions (userinfo.email and userinfo.profile); the add-on itself does not use these values. See our Privacy Policy for details.

Why does Table Formatter show “Action not allowed”?

One possible cause is having multiple Google accounts signed in within the same browser profile. Google documents this as a limitation affecting Apps Script add-ons. See Google's troubleshooting guidance.

To get Table Formatter working:

  1. Open an Incognito or private browsing window.
  2. Sign in only to the Google account where you installed Table Formatter.
  3. Open your document, choose Extensions → Doc Table Formatter → Open sidebar, click inside your table, and try again.

For everyday use, use a separate browser profile for each Google account, with only one account signed in per profile. You can keep your accounts open in separate profile windows without signing out each time. See Google's browser profile setup instructions.

If the error continues with only one account signed in, confirm that you can edit the document, then contact support. Include the exact error and which button you clicked. Multiple accounts are a possible cause, not the only cause.

Reporting an issue

When emailing support, please include:

  • A description of what you tried and what happened
  • The exact error message and which button you clicked (expand Technical details in the sidebar if available)
  • A screenshot, if possible
  • Your browser and operating system
