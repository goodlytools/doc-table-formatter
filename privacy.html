Privacy Policy

Last updated: September 13, 2026

This Privacy Policy explains how the Doc Table Formatter Google Workspace add-on (referred to as "the Add-on") handles user data. Doc Table Formatter is published by Goodly Tools, a personal project operated by Michael DeSandoli, contactable at support@goodlytools.ca. The Add-on is offered free of charge through the Google Workspace Marketplace.

Short version: the Add-on runs entirely inside your Google Docs session. It does not collect, store, transmit, sell, or share any personal information or document content. Nothing leaves your Google account.

1. What Google permissions the Add-on requests

When you install or first open the Add-on, Google will ask you to grant the following OAuth scopes. Each is used only for the purpose stated below.

https://www.googleapis.com/auth/documents.currentonly

Grants access only to the single Google Doc you have actively opened when you invoke the Add-on. The Add-on uses this scope to read the structure of the table containing your cursor (rows, columns, cells) and to apply table-formatting changes (cell background color, text bold styling, column widths) to that same table. It cannot see, read, or modify any other document in your Google Drive.

https://www.googleapis.com/auth/script.container.ui

Allows the Add-on to render its own user interface inside Google Docs: specifically, the sidebar that contains the formatting controls (via DocumentApp.getUi().showSidebar()) and the Extensions → Table Formatter menu item (via DocumentApp.getUi().createMenu()). This scope is used solely to display the Add-on's own controls; it is not used to load external web content, host third-party pages, or display advertising.

https://www.googleapis.com/auth/userinfo.email and https://www.googleapis.com/auth/userinfo.profile

These scopes are added automatically by the Google Workspace Marketplace framework. They allow Google to identify the signed-in user for installation and for support inquiries. The Add-on itself does not access, store, transmit, or use the values returned by these scopes.

2. What data the Add-on does not collect

The Add-on does not:

  • Collect, transmit, or store any document content, personal data, or usage analytics.
  • Send data to any external server or third-party service. There is no backend.
  • Use tracking pixels, advertising SDKs, analytics libraries, or fingerprinting.
  • Share, sell, rent, or trade user data with any third party.
  • Persist user data using Google Apps Script's PropertiesService, CacheService, or any external database.

All logic runs inside the Google Apps Script runtime attached to your active Google Docs session. Formatting changes are made directly to your document through the Google Docs API; no copy of your document content is transmitted anywhere else.

3. Data retention

Because the Add-on does not collect or store any user data, there is nothing to retain and nothing to delete. Your document content stays where it always was — in your own Google Drive under your Google account.

4. Your rights and control

You can uninstall the Add-on and revoke all granted permissions at any time from your Google Account:

  • In Google Docs: Extensions → Add-ons → Manage add-ons, then uninstall Doc Table Formatter.
  • To revoke OAuth access separately: visit myaccount.google.com/permissions, locate Doc Table Formatter, and remove access.

Because no data is stored on any server we operate, uninstalling the Add-on removes all access. There is no separate data-deletion request to make.

5. Third-party services

The Add-on does not integrate with, or transmit data to, any third-party service other than the Google APIs required to display its sidebar and edit the currently open document. It does not use external analytics providers, error-tracking providers, or advertising networks.

6. Children's privacy

The Add-on is not directed to children under 13. It does not knowingly collect any information from children, because it does not collect information from any user.

7. Security

The Add-on operates within Google's Apps Script runtime and inherits Google's security posture for Google Workspace add-ons. Because the Add-on has no server component, it does not transmit or store credentials, tokens, or user content outside of Google's infrastructure.
