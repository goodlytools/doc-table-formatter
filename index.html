Doc Table Formatter

A free Google Docs add-on for fast, consistent table formatting — from a sidebar inside your document.

Doc Table Formatter is a Google Workspace add-on published by Goodly Tools that helps you style tables in Google Docs without leaving your document. It runs entirely inside the Google Doc you have open: pick a table with your cursor, open the sidebar, and apply header styling, row or column banding, custom fill colors, and column-width adjustments in one click.

The add-on only ever touches the single document you have open. It never reads, modifies, stores, or transmits any other document, and it has no external server.

Get the add-on

The Google Workspace Marketplace listing is currently under review. Public installation is not yet available.

What it does

  • Header & special-row styling. Bold text for Header Row, Total Row, First Column, and Last Column — toggle any combination.
  • Header fill color. Pick from a preset palette or use a full color picker with hex input for exact brand colors.
  • Row or column banding. Alternate two colors across rows or columns, with customizable odd/even values and a one-click swap button.
  • Column-width tools. Distribute Columns evenly, or use Best Fit to minimize overall table height based on cell content.
  • One-click Apply and Clear. Apply your current settings to the selected table, or strip formatting back to defaults.

How to use it

  1. After public approval, install Doc Table Formatter from the Google Workspace Marketplace. If you already have the add-on installed, continue below.
  2. Open any Google Doc that contains at least one table.
  3. Click Extensions → Doc Table Formatter → Open sidebar.
  4. Place your cursor inside the table you want to format.
  5. Choose your styling options in the sidebar and click Apply.

What permissions it needs

Doc Table Formatter requests only the minimum Google permissions it needs to render its sidebar and format the table in the document you have open:

  • .../auth/documents.currentonly — access only the Google Doc you are actively editing when you open the add-on, so it can read the table structure and apply formatting. It cannot see any other document in your Drive.
  • .../auth/script.container.ui — display the add-on's sidebar and the "Extensions → Doc Table Formatter" menu item inside Google Docs. This is used solely to render the add-on's own user interface.
  • .../auth/userinfo.email and .../auth/userinfo.profile — required by Google Workspace Marketplace to identify the signed-in user during installation and for support requests. The add-on itself does not use these values.

See the Privacy Policy for full details on what the add-on does and does not do with your data. Short version: nothing leaves your Google account.
